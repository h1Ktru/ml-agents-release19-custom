# カスタム版 ML-Agents (Release 19)

Unity公式の [ML-Agents Release 19](https://github.com/Unity-Technologies/ml-agents/releases/tag/release_19) をベースに、独自の改造を加えたリポジトリです。

## 変更点 (What I modified)
* トレーニング中に独自の成功率（Success Rate）パラメータを追跡できるように内部スクリプトをカスタマイズしました。
* コマンドプロンプトにカスタム評価ログが出力されるように変更しています。
